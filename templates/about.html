HydroMonitor

Sistema de monitoramento hidrológico acadêmico, feito com Python e Django. Exibe estações, observações de nível do rio (m) e precipitação (mm/h) por meio de gráficos. Os dados são sintéticos e servem apenas para demonstração.

Endpoints da API

As consultas (GET) são públicas. Criar, alterar e excluir exige autenticação.

MétodoRotaDescrição
GET/api/Raiz da API
GET/api/stations/Lista as estações (filtros river, municipality; search)
GET/api/stations/{id}/Detalhe de uma estação, como EST-01
GET/api/stations/{id}/summary/Estação, total de observações e última leitura de cada métrica (exemplo)
GET/api/stations/{id}/series/Série histórica: metric (level ou rain) e hours (1 a 720) (exemplo)
GET/api/observations/Lista as observações (filtros station, metric, source, observed_after, observed_before; ordering)
GET/api/observations/{id}/Detalhe de uma observação
POST, PUT, PATCH, DELETE/api/stations/ e /api/observations/Escrita, com token ou sessão
POST/api/token/Obtém o token de autenticação
